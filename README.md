# ZLAT Website

Official company website for ZLAT Ltd., a Bulgarian manufacturer and service provider specializing in industrial metal detectors and custom detection systems.

The website presents the company’s services, industrial applications, project gallery, history, and contact information. It is built with Astro and Tailwind CSS, with a focus on performance, responsive design, accessibility, and search engine optimization.

## How to run the project

Install the dependencies and start the local development server:

```sh
npm install
npm run dev
```

Create and preview a production build:

```sh
npm run build
npm run preview
```
