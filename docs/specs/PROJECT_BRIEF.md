# ZLAT EOOD Industrial Website

## Goal
Fast, responsive company website for ZLAT industrial metal detector services.

## Tech Stack
- Astro
- Tailwind CSS
- HTML-like Astro components
- Minimal JavaScript

## Pages
- Home
- Services
- Gallery
- About
- Contacts

## Rules
- Do not use React.
- Do not use Next.js.
- Do not use shadcn/ui.
- Use Astro components.
- Use Tailwind for styling.
- Keep the website fast and responsive.
- Do not use database.
